## 3. Golden files

The 16 Copy as/Export grid rows formats and the SQL export follow HeidiSQL's code as described in appendices B and C, with format tests. They still have to be compared with files generated by HeidiSQL itself (pending A1 and A2).

## 4. Soak and stalls

- Automatic soak: `EUNOMIA_SOAK_MINUTES=N` runs the cycle of queries, metadata, export, Run SQL file and CSV import, and fails if managed memory grows by more than 20% + 20 MB. The result of the short run on this machine is in `docs/progress.md`.
- The 24 h run and the E2E suite on the real UI are left for the reference machine (pending B3 and B4).
